A small script that generates a formatted resume as a .docx file.

To run it locally:

```bash
npm install docx
node resume.js
```

It outputs `Rajesh_Sood_Resume_2025.docx` in the current directory. Any time you want to
tweak content — a new job, updated metrics, different wording — edit the relevant
section in `resume.js` and re-run. No Word needed.
